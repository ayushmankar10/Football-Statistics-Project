## Data sources and limitations

This project uses publicly available match statistics from the sources I could access. Some data may be incomplete because I do not have access to full professional data feeds.

Sources are recorded in the CSV so the figures can be checked. Statistics from different providers may use different definitions or models, particularly for xG and xA. Unavailable values are marked as NA rather than estimated.

The analysis is exploratory and should be interpreted with these limitations in mind.
